
# Phishing Link and Scam Message Checker

## About
A beginner-friendly Python project that helps identify potentially suspicious links and scam messages.

## Features
- Checks suspicious URLs.
- Analyses potentially fraudulent messages.
- Provides warnings for potentially unsafe content.

## Technologies Used
- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

python phishing_scam_checker.py
